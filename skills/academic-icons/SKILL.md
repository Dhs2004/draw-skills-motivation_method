# Academic Icons：DEPPO 风格的小图标

先查看 [图标总览](assets/catalog.png)，再按 [语义索引](references/catalog.md) 选取素材。素材库包含本项目 DEPPO motivation / method 重绘版实际使用的 23 种图标；不是从原论文 PDF 提取的完整图标集。可以单独使用本 skill，也可用于已有概念示意图的局部润色。

## 选择与密度

- 图标对应图中已有的实体、操作或状态：机器人表示策略／模型，奖杯表示成功，警示表示失败风险，放大镜表示检索，滑块表示幅度调节，软盘表示写入，幼苗表示新鲜经验，时钟与垃圾桶表示衰减／清理。完整角色见索引。
- 用户要求增加图标时，先找缺少视觉提示的真实机制，再为它们配图标并调整文字位置；不把总数、翻倍或每框一个图标作为固定标准。DEPPO 的 20／30 个实例只是当时两张图的布局结果，不是新图的最低数量。
- 相同角色跨模块尽量使用相同图标，成功与失败可使用不同图标区分。图标不能替代关键文字：门控图标需搭配条件，奖杯不表示形式化最优保证，警示不等于所有失败动作都错误。
- 库中素材不能准确表达新机制时，可以寻找同风格的新图标；优先原色彩色描边／卡通系列。记录具体来源、作者和许可，不能假称已访问未浏览的网站。

## 尺寸与布局

- 参考约 1500 px 宽画布：主体图标常用 44–60 px，模块图标 30–42 px，行内提示 24–32 px，火焰等状态角标 18–24 px。按可见轮廓和图标复杂度调整，不机械套值；书本和笔记应能辨认。
- 保留原色与宽高比。透明边距可裁去；给定宽高框时，用 `scale=min(box_width/image_width, box_height/image_height)` 同时约束两维，再居中放置。交通灯、滑块等细长图标尤其不能只约束宽度，避免其高度覆盖下一行。
- 文字和图标之间通常保留 6–10 px 安全距离；检查整段文本矩形，不只检查文字起点。增加图标需要同步缩短标签、移动文字或调整行高；不要直接塞入现有文字区域。
- 手绘斜线填充用于原生模块背景，不覆盖到实体图标上。框线、箭头、token、曲线仍用原生图形；公式 SVG 与实体图标分开统计。
- 图标不应跨越两行造成错误归属，不遮挡标题、公式、反馈箭头或数值。细长状态图标、贴边奖杯和小型天平都需要看最终预览确认比例。

## 素材与嵌入

PNG 文件在 `assets/icons/`，部分附原始 SVG；[manifest.json](assets/manifest.json) 记录相对路径、语义、像素尺寸、来源、处理方式和 SHA-256。不要为没有保存矢量源文件的 PNG 虚构 SVG。

编辑已有 Excalidraw 前备份当前源文件，保留已有元素 ID 与用户改动。新增图片以 data URL 写入 `files`，元素 `fileId` 引用其条目，保持比例和 `scale=[1,1]`；不用远程热链。改文字同步维护 `text`、`originalText` 和实测尺寸；移动绑定元素时维护连线关系。不能重新运行旧构图脚本覆盖当前画布。

OpenMoji 素材使用 CC BY-SA 4.0，见 [许可副本](assets/OpenMoji-LICENSE.txt)；机器人、书本和天平等复用 Flaticon 资产的具体作者及出版许可未完全核实，manifest 明确区分，不能将全库称为免署名可商用素材。保留素材来源和修改记录，不把论文接收等同于第三方图标授权。

## 交付检查

从修改后的同一源文件重新导出图像；检查图文／图图遮挡、透明边界、比例、文本量字及 PDF 表现。保留来源文件与可编辑源文件，实际查看整图和最密集局部。学术数据图一般不自动添加装饰图标。

新增素材后更新 manifest 与语义索引，再用 Pillow 重建总览：

```bash
python /path/to/academic-icons/scripts/build_catalog.py
```

调用示例：`使用 academic-icons skill，为这张方法图的经验查询、门控、优势调节和记忆维护补充 DEPPO 风格的小图标，调整图文间距并保持原有公式比例。`
