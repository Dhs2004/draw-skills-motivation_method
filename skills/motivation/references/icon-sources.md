# 图标来源与选型

默认优先搜索 Flaticon 的 colorful outline / cartoon / cute / sticker 类图标，按语义选实体，再筛选一致的描边粗细、色彩饱和度和视角。查看实际图片，不只依赖搜索标签。使用现有工具或公开可访问的页面/下载链接；网页不可访问时可以使用已知素材或其他适当来源，不伪称已查到作者/授权。

本 skill 的 ../assets/icons/ 是这次制作的可复用样例图标，保留原色与卡通适配。机器人保持下载原样；book/checklist 为彩色描边素材，部分其他图标曾做上色或轮廓适配。并非全部素材原本就是“动漫图标”。只有语义适合时才用，不能把它们全塞进每张图。

已实际使用的 CDN 模式：`https://cdn-icons-png.flaticon.com/512/{floor(id/1000)}/{id}.png`。详情页可由搜索得到，`https://www.flaticon.com/free-icon/{name}_{id}` 仅是参考地址，不能据此认定网页访问成功。

这些样例的作者、具体许可与出版授权未核实，当时详情页返回 403。下载成功不表示取得出版或商业授权。为实际项目记录 URL、作者（已知时）、许可状态及是否做过改色；按实际许可保留署名信息。不要把未核实素材描述成免署名、可自由出版。用户已有授权素材优先。

图标内嵌为 data URL，Excalidraw files 中 fileId 必须对应存在；不能依赖临时绝对路径或网络热链。PNG 足够清晰即可，不需要为每个图标生成矢量轮廓。不要把图片实体改成手绘矢量以掩盖素材来源。

另含 OpenMoji 火焰、问题、目标、剪刀、秒表、闪电、链环、指南针等素材；具体 URL 和 CC BY-SA 4.0 许可记录在 assets/icons 中，示例范围见 [public-examples.md](public-examples.md)。
