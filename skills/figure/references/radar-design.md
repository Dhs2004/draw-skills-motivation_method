# 彩色外环雷达图：六种精细变体

这些风格与已有图表示例同级，全部使用同一份 7×6 模拟数据、同一任务顺序和 0–100 线性半径。改变的是视觉呈现，不是数据、任务数或归一化。六种风格的编号仅用于对照总览，不是算法步骤。

| 风格 | 中文名称 | 视觉取舍 |
|---|---|---|
| pastel_bloom | 柔彩花环雷达图 | 宽低饱和彩环、细外缘、衬线标签与莓红主线，适合温和的论文版式 |
| jewel_arc | 宝石色弧环雷达图 | 饱和度适中的实色环、白字、深蓝主线，外环层次鲜明 |
| porcelain_double_ring | 青瓷双层环雷达图 | 细彩色外缘与淡色标签环分离，青绿色主线，线条更轻 |
| aurora_gradient | 极光渐变环雷达图 | 每段外环由内向外渐变，紫色主线；渐变完全由矢量色带组成 |
| faceted_spectrum | 棱面彩环雷达图 | 六边形同心网格、分段彩环、轴端小点，强化几何秩序 |
| minimal_ribbon | 极简彩带雷达图 | 窄彩带、外置水平标签与淡色小底框，图内更简洁 |

## 关键实现

- 数据中心为零，外层数值网格为 100；任务彩环位于数值区域之外，颜色仅表示任务。不能用环宽或弧长暗示得分。
- 主曲线使用稍粗描边和空心圆点；其他曲线用克制的颜色、线型和小标记区别。浅填充只用于主曲线，不把所有多边形叠成一块浑浊色团。强调 Candidate 是设计选择，不表示它在每个任务都最高。
- 标签沿弧切线旋转；位于下半圈时翻转为易读方向。极简彩带版将标签水平放在外部，留足边界，不能裁切。
- 径向刻度放在辐条之间，配小白底，避免与数据线和任务标签重叠；保留 20、40、60、80、100 的共同尺度。
- 图例位于独立的底部区域，顺序与曲线身份一致，所有七条曲线均保留。不得为美观悄悄删掉不利基线、改轴顺序或改变半径下限。
- 渐变外环用矢量分带形成，适合 PDF/SVG；图内不要使用阴影、发光或 3D 透视扭曲数值距离。
- 在最终论文栏宽查看，而不是仅看高清原图。图例太小时应调整布局／字号，或根据用户明确选择减少系列；不能无说明隐藏系列。

## 重放

依赖 NumPy、Matplotlib、Pillow。脚本接受带 `synthetic: true` 和 `radar` 数组的 JSON，数据必须为 7×6 且在 0–100 范围。

```bash
python /path/to/figure/scripts/render_radar_gallery.py \
  --data /path/to/figure/assets/examples/radar_data.json \
  --out /path/to/radar-gallery
```

输出六张 360 dpi PNG、单页矢量 PDF、SVG、独立预览、总览及 JSON/CSV。SVG 保留文本，跨设备可能受字体影响；PDF 嵌入字体。当前样例标注模拟数据，真实数据的使用应调整输入读取与来源标注，而不是只去掉免责声明。
