# 彩色卡通图标

优先在 Flaticon 搜索 colorful outline / cartoon / cute / sticker 系列，按参考中的实体选图，不必拘泥于旧图标。统一描边、饱和度和视角；实际查看图片，避免可爱机器人混用写实或纯黑实心图标。可用语义合适的 OpenMoji 或用户素材补充，并记录实际来源。网页不可访问不伪称已浏览。

../assets/icons/ 包含当前样例素材与来源记录；其中有 Flaticon 机器人、雪花、书本、奖杯、天平，以及 OpenMoji 火焰、环境、剪刀、笔记、目标。详细说明见 [public-examples.md](public-examples.md)。Flaticon 作者及出版许可尚未核实，不能宣称免署名可自由出版；OpenMoji 保留其 CC BY-SA 4.0 许可和修改记录。

新项目按图标记录来源 URL、作者（已知时）、许可状态和裁剪/改色情况。素材下载成功不等于授权确认。不要因为缺少全新图标而重复添加无意义符号，也不要把旧图标数目作为指标。

按可见轮廓比较尺寸，裁去多余透明边距并保持宽高比。主实体、复杂笔记、从属状态标记分别定尺寸；笔记不能缩成不可识别的角标。以 Excalidraw files 的 data URL 内嵌图片，核实 image 的 fileId，不能依赖网络热链或固定绝对路径。实体使用图片，框线/箭头/直方图/轨迹/标签使用原生组件。


新增素材应按当前方法的语义主动选择，不必完全复用已有机器人、书本等图标。例如随机采样可用骰子，评分核验可用勾/叉，计算或更新可用算盘/齿轮，参考约束可用盾牌，因果可见性可用锁，归一化分布可用柱图。它们是可选的语义映射，不是必须装入每张图的清单。特别注意方法真实含义：盾牌不能暗示形式化安全保证，齿轮不能代替具体更新规则。

图标放在对应操作、状态或结果旁，并与文字留出安全间距。重复模型身份时风格和尺寸一致；简单状态标记可更小，复杂实体须保留可辨细节。图标数量不足时补充缺少视觉提示的实际机制；已有足够提示时不要再以重复图标填空白。矩阵、token 行、分布条形、多头分支和连接线仍优先用 Excalidraw 原生工具绘制。
