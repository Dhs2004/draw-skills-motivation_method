# 风格与布局参考

先看 [GRPO 示例](../assets/grpo/motivation.png) 和 [Transformer 示例](../assets/transformer/motivation.png)。它们展示卡通字体、彩色实体、白底黑线与紧凑对比结构；不要复用具体算法结论。对应 motivation.excalidraw 可用于检查样式属性。论文和素材信息见 [public-examples.md](public-examples.md)。

## 尺度起点（画布坐标，不是印刷 pt）

| 对象 | 建议起点 |
|---|---|
| 主标题 | 28–34，Comic Shanns |
| 模块标题 | 23–28，必要时两行 |
| 正文 | 16–18；辅助标签通常不低于 14 |
| 主实体图标 | 48–72 |
| 书本、清单等有细节图标 | 40–48，不能默认做成 20 px 角标 |
| 简单从属图标 | 24–32，仅限仍可辨认的符号 |
| 主边框 | 深灰 #252525，strokeWidth 2–2.2，roughness 0.85–1 |
| 次边框 | strokeWidth 1.3–1.7 |
| 语义色 | 箭头 #df3b3b；成功 #3c8061；失败 #ae4b55 |
| 柔和填充 | 白色为主，可用 #fff9e8、#f0f8fc、#d5e9dc |
| 图文安全间距 | 6–10，按实际文字边界判断 |
| 模块间距 | 8–14；外边距 16–24，密度足够时可更小 |

这些是起点，不是硬性模板。图标 PNG 可能包含透明边缘，应按可见轮廓比较尺寸。保证原始宽高比。Comic Shanns 不覆盖所有中文；中文可使用 Excalidraw 的 Excalifont（family 5）及其 Xiaolai 中文回退字体，并检查渲染、导出字体嵌入；不要让中文成为方框。

## 高密度排版的顺序

1. 找最大的无信息矩形：常见于宽说明栏、独占一行的标签、标题下方空隙、低矮内容被等高容器撑开。
2. 缩窄说明栏并按语义断行；尽量保持正常字号。两个短特性标签并排，比两条横贯整栏的标签更节省空间。较长标签可以自然分两行。
3. 以真实内容边界确定模块高度；让图示与说明共同填满模块，不将所有模块强制等高到最大的那一个。
4. 调整机制图布局：短轨迹一行，多个阶段在空间允许时并置，必要时用两行闭环；不用多余说明重复已有标题。
5. 再调整间距和装饰。不要使用坐标整体乘系数但文字不缩放的粗暴压缩，这会造成 token 边框、字形和标签碰撞。
6. 查看最终尺寸下的图；把画布缩小却让读者必须放大阅读不算成功。

若需近似最终示例，约 700×840 的竖版是三组对比的可行起点，但不能给任意参考图硬套这个尺寸。不要无依据添加反馈闭环。

## 避免本次已出现的问题

- 黑白灰只用于组件为主；保留彩色图标本身。
- 优先同一图标套系/视觉语言，不能把一个可爱机器人与大量写实、纯黑实心符号混用。
- 字体不混用多套装饰字体；先统一 Comic Shanns。Excalifont 比当前示例更潦草，Nunito 更常规，不是默认风格。
- 笔记图标 26–31 px 在此尺度偏小；40–42 px 才能清楚表达。放大后重新分配空间，不能挤压文字。
- 标题/标签要留在其容器中；≠、括号、箭头和大写字母都有超出名义锚点的可见轮廓。
- 图片与文本矩形相交是警报；机器人与手持书本的有意叠放单独判断。不能以“图标透明区域”推断没有遮挡而不看图。
- 不保留多版本相互矛盾的说明。当前 `.excalidraw` 为唯一权威源，SVG/PNG/PDF 均从同一版本导出。


## Method 图的横向分支

用户已明确：方法图的主流程应横向展开，不能沿用 Motivation 图的纵向默认。可参考约 2.0–2.4:1 的宽幅比例；例如采样、评分、优势计算与策略更新从左到右展开，阶段内部保留必要的上下层次。机制细节可以比动机图更丰富，但必须来自参考图，不能为了填空白而编造步骤。

加强手绘感时使用原生略不规则轮廓（主框 roughness 约 1.1–1.4）、斜线填充及适量红色流程线；仍保持文字整齐、公式清晰。为任务、模型、环境、反馈、比较和控制等真实实体配置图标，主图标与火焰/雪花等从属状态标记分级定尺寸；不要把状态标记扩大到与模型同级。文字和图标之间的间距检查必须在最终导出后进行。
